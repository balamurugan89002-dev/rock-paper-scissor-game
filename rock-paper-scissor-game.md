#Rock Paper Scissors Game

#Project Overview

A simple Rock Paper Scissors game built as a beginner-friendly web project. The player chooses Rock, Paper, or Scissors, and the computer makes a random choice. The game displays the result and keeps track of the score.

#Objective

Build an interactive Rock Paper Scissors game that demonstrates basic programming and web-development concepts such as:

- User input
- Random choices
- Conditional statements
- Functions
- Event handling
- DOM manipulation
- Updating webpage content

#Workflow

1. The player selects Rock, Paper, or Scissors.
2. The computer randomly selects one of the three choices.
3. The game compares the player's choice with the computer's choice.
4. The result is displayed as Win, Lose, or Draw.
5. The score is updated.
6. The player can continue playing.

#Tech Stack

HTML

Used to create the structure of the game page, including buttons, headings, score areas, and result sections.

CSS

Used to design the game interface, including layout, spacing, colors, buttons, and responsive styling.

JavaScript

Used to make the game interactive. JavaScript handles:

- Player input
- Computer's random choice
- Game rules
- Win/Lose/Draw logic
- Score updates
- Updating the displayed result

Git & GitHub

Git is used for version control, while GitHub is used to store the project repository online.

GitHub Pages

GitHub Pages is used to host the game so it can be accessed through a public web URL.

#How the Tech Stack Works Together

HTML → CSS → JavaScript → Git/GitHub → GitHub Pages

- HTML creates the webpage structure.
- CSS makes the webpage look better.
- JavaScript adds game logic and interaction.
- Git tracks project changes.
- GitHub stores the project repository.
- GitHub Pages publishes the project on the web.
